# Frontend - Next.js (Absensi SPPG)

Aplikasi Web Client untuk sistem **Absensi SPPG** yang dibangun menggunakan **Next.js**.

---

## 🛠️ Panduan Memulai

### Prasyarat
- Node.js (v18.x atau lebih baru)
- npm / yarn / pnpm

### Instalasi & Menjalankan Dev Server
```bash
# Masuk ke direktori frontend
cd frontend

# Install dependencies
npm install

# Jalankan server development
npm run dev
```

Server frontend akan berjalan di `http://localhost:3000`.

---

## 🌟 Fitur Frontend
- **Halaman Presensi Interaktif:** Akses kamera & validasi geolokasi GPS real-time.
- **Dashboard Pegawai:** Ringkasan jadwal shift, riwayat presensi, dan status pengajuan izin.
- **Admin Management Panel:** Tabel data pegawai, monitoring unit SPPG, dan persetujuan izin.
